# Faqihna Fiddin Alfarizi — Cloud & DevOps Engineer Portfolio

Personal portfolio website built with an interactive **Cloud Control Plane & Multi-Cloud Infrastructure Topology** UI/UX.

## 🚀 Key Features
- **Interactive Multi-Cloud Topology Visualizer**: Inspect live Kubernetes cluster configurations across **AWS (EKS)**, **Google Cloud (GKE)**, and **Tencent Cloud (TKE)**.
- **Zero-Downtime CI/CD Rollout Simulator**: Interactive 5-stage deployment pipeline simulation (`Git & GitLab` ➔ `Docker Build` ➔ `Azure Key Vault & External Secrets` ➔ `Kubernetes Rollout` ➔ `Prometheus Health Probes`).
- **Command Palette (`Ctrl + K`)**: Quick navigation, instant email copy, live rollout simulation trigger, and Dark/Light Console theme toggle.
- **Production Experience & Incident Runbooks**: Showcasing DevOps Engineering experience at **PT Link Net Tbk** along with production Kubernetes troubleshooting runbooks (`ImagePullBackOff`, `CrashLoopBackOff`, secret rotation).
- **Printable / ATS Resume (`cv.html`)**: Clean, print-ready CV page with one-click **Print / Save as PDF**.

## 🛠️ Tech Stack Highlighted
- **Cloud Platforms**: Google Cloud Platform (GKE), Amazon Web Services (EKS, EC2, IAM, VPC), Tencent Cloud (TKE)
- **Containers & Orchestration**: Kubernetes (EKS, GKE, TKE, K3s), Docker, Docker Compose
- **CI/CD & Secret Management**: Azure DevOps Pipeline, GitLab CI/CD, GitHub Actions, Docker Hub, Azure Key Vault, External Secrets
- **Monitoring & Observability**: Prometheus, Grafana, Node Exporter, InfluxDB
- **Operating Systems**: Linux, Ubuntu

## 📂 Project Structure
- `index.html` — Main interactive portfolio (Cloud Control Plane UI)
- `style.css` — Dark/Light Telemetry Console styling, Bento grid, and responsive layout
- `script.js` — Multi-cloud topology switcher, CI/CD rollout simulator, and `Ctrl+K` Command Palette
- `cv.html` — Printable ATS-friendly CV page
